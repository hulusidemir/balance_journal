# Trade Wallet Tracker

A web application to track your trading wallet, calculate trade targets, and monitor your progress against a daily profit goal.

## Features

- **Trade Calculator**: Calculate position size, target profit, and exit price based on balance, leverage, and entry price.
- **Balance Tracking**: Track your daily balance and compare it against a compound interest plan.
- **Settings**: Configure your starting balance, start date, and daily profit target.
- **Responsive Design**: Works on desktop and mobile.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
